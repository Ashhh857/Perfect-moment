HOW TO PUBLISH ON GITHUB PAGES
--------------------------------
1. Go to your existing repo: https://github.com/ashhh857/Perfect-moment
2. Delete the old files (or just upload these new ones - GitHub will ask
   to replace files with the same name).
3. Upload ALL files/folders from this package (keep folder structure):
   index.html, style.css, script.js, sitemap.xml, robots.txt, 404.html,
   assets/ (all images)
4. Commit changes to the "main" branch.
5. Settings > Pages should already be set to "Deploy from branch: main /
   root" - if not, set it now and Save.
6. Wait 1-2 minutes, then visit https://ashhh857.github.io/Perfect-moment/
   to confirm it is live with all the changes.

AFTER PUBLISHING - GOOGLE INDEXING STEPS (free, 10 minutes)
--------------------------------------------------------------
1. Go to https://search.google.com/search-console
2. Add property > URL prefix > enter:
   https://ashhh857.github.io/Perfect-moment/
3. Verify ownership using the "HTML tag" method (Google gives you a
   <meta name="google-site-verification" ...> tag - paste it inside the
   <head> of index.html, commit, then click Verify in Search Console).
4. Once verified, go to Sitemaps (left menu) and submit:
   sitemap.xml
5. Use "URL Inspection" and click "Request Indexing" for your homepage URL
   to speed up Google crawling.
6. Also create/claim your free Google Business Profile
   (business.google.com) with the same name, address, phone and category
   "Event Planner" / "Decorator" - this is what makes you show up on
   Google Maps for "decoration near me" searches in Lucknow.
